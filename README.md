# Nozom System

نظام CRM داخلي خفيف مبني كصفحات HTML ثابتة ومتصل بدوال Supabase RPC.

## الصفحات

- `admin.html`: لوحة المدير والمشرفين والتقارير والحضور والعملاء والتكليفات والزيارات.
- `employee.html`: صفحة الموظف. الرابط المخصص يدخل الموظف مباشرة، مع إبقاء اختيار الفريق والموظف كمسار احتياطي.
- `guard.js`: يتحقق من حالة تشغيل النظام قبل عرض الصفحات.
- `quality.html`: دخول مراقب الجودة؛ المدير يضبط كلمة مروره من الإعدادات.
- `quality.js` و`quality.css`: واجهة المراجعات المشتركة مع المدير والمشرف. المسودة تظهر للمدير ومراقب الجودة، والمرسلة تظهر لمشرف التيم للرد؛ الإغلاق للمدير ومراقب الجودة.
- `index.html`: يحول إلى لوحة الإدارة.

## التحقق المحلي

```powershell
npm test
```

الاختبار يفحص صياغة JavaScript، وصحة بداية HTML، ونظافة وسوم المكتبات الخارجية، وعدم حفظ كلمة مرور الإدارة في `localStorage`.

`tests/quality-access.sql` يختبر مسار المسودة والإرسال والرد والإغلاق وعزل التيمات داخل معاملة يتم التراجع عنها. إضافة الجودة تحفظ البيانات في `quality_reviews` و`quality_findings` عبر `quality_api`؛ الوصول المباشر للجداول ممنوع.

## النشر

الفرع `main` مرتبط بـ Vercel. أي push ناجح يبدأ النشر تلقائيًا. يجب إبقاء تعريفات Supabase والجداول ودوال RPC في migrations منفصلة عند إضافة تغييرات إلى قاعدة البيانات.
